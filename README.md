# Essientr Portfolio (2024)
🇹🇷 [Türkçe](README.tr.md) | 🇬🇧 [English](README.md)

One of the first personal portfolio projects I built back in 2024. I'm sharing it exactly as it was, made with the knowledge I had at the time, to show how I've grown since then.

Today I would build the same project very differently, but everyone starts somewhere, and my journey started with this project. There were things before it, but personally I'd say this is where it really began.

## ✨ Features

* Single-page, mobile-friendly design
* Home, about and skills sections
* Light / dark theme support (preference is stored in `localStorage`)
* Active menu links based on scroll position
* Entrance animations with ScrollReveal
* Custom 404 page
